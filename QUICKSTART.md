# QUICKSTART.md

Get the AI Test Generator running in 5 minutes.

## 1. Prerequisites Check

```bash
# Check Python
python3 --version  # Should be 3.9+

# Check Node
node --version     # Should be 18+
npm --version      # Should be 8+
```

## 2. Get API Key

1. Go to https://console.anthropic.com/
2. Click "Create API key"
3. Copy the key

## 3. Setup Backend

```bash
# Create virtual environment
python3 -m venv venv
source venv/bin/activate  # macOS/Linux

# Install dependencies
cd backend
pip install -r requirements.txt

# Configure API key
cd ..
cp .env.example .env
# Edit .env, paste your API key: CLAUDE_API_KEY=sk-ant-...
```

## 4. Setup Frontend

```bash
cd frontend
npm install
```

## 5. Run Both Services

**Terminal 1 - Backend:**
```bash
cd backend
python app.py
# Runs on http://localhost:8000
```

**Terminal 2 - Frontend:**
```bash
cd frontend
npm run dev
# Runs on http://localhost:5173
```

## 6. Test It Out

Open http://localhost:5173 in your browser:

1. **Upload Sample File**
   - Click the upload area
   - Select `sample_auth.py` or `sample_api_spec.json`
   - Wait for "✓ chunks added" message

2. **Generate Tests**
   - Write query: `Generate pytest tests for user authentication`
   - Select "Pytest (Unit Tests)"
   - Click "Generate Tests"

3. **View Results**
   - See generated test code
   - Click citations to see source
   - Copy code to clipboard

## Troubleshooting

**Backend won't start:**
```bash
# Make sure you're in venv
which python  # Should show venv/bin/python

# Test imports
python -c "import fastapi, anthropic, faiss; print('OK')"
```

**CORS error in browser:**
- Backend must be running on http://localhost:8000
- Check no firewall blocking port 8000

**Test generation returns empty:**
- Make sure file was uploaded successfully
- Check index status: curl http://localhost:8000/index-status
- Try a different query

**"CLAUDE_API_KEY not found":**
- Verify .env file exists in project root
- Check key starts with sk-ant-
- Restart backend after editing .env
